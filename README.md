## APK

O site já está configurado. Para liberar o botão **Baixar**, você só precisa colocar o arquivo:

`dist/flexlog.apk`

Use exatamente o nome:

`flexlog.apk`

Depois que o APK estiver publicado junto com o site, o botão muda automaticamente de **Em breve** para **Baixar**.

## Estrutura pronta

- `dist/app.js`
