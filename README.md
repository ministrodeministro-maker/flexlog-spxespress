## APK

O site já está configurado e conectado ao GitHub.

Para liberar o botão **Baixar**, coloque apenas o arquivo:

`dist/flexlog.apk`

Use exatamente o nome:

`flexlog.apk`

Depois do upload no GitHub, a Vercel publica automaticamente a nova versão. O botão muda de **Em breve** para **Baixar** quando o arquivo estiver disponível.
